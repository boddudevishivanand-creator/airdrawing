# ✋ Air Drawing using Computer Vision

## 📌 Overview
This project allows users to draw in the air using hand gestures captured through a webcam. It uses computer vision techniques to track hand movement and convert it into digital drawings.

## 🚀 Features
- Draw in air using finger gestures
- Real-time hand tracking
- Multiple colors and drawing modes
- Erase functionality

## 🛠 Tech Stack
- Python
- OpenCV
- NumPy
- MediaPipe (if used)
